# نظام المراسلات الداخلية — مديرية مالية اللاذقية

نظام ويب عربي كامل لإدارة المراسلات الداخلية (وارد / صادر / أرشيف) يعمل **دون إنترنت** على الشبكة المحلية للمديرية، مع قاعدة بيانات SQL Server وإشعارات فورية ومرفقات.

## المكوّنات

| الجزء | التقنية |
|---|---|
| الواجهة | React 19 + TypeScript + Vite + Tailwind CSS + Framer Motion |
| الخادم | Node.js 20 + Express + Socket.IO |
| قاعدة البيانات | Microsoft SQL Server 2022 (أو 2019) |
| المصادقة | JWT + bcrypt |

## الحسابات الافتراضية (تُنشأ عند الإعداد الأول)

| الحساب | اسم المستخدم | كلمة المرور |
|---|---|---|
| مدير النظام | `admin` | `Admin@2026` |
| مدير المديرية | `director` | `Director@2026` |
| رؤساء الأقسام | `budget.head` `accounts.head` `salaries.head` `tax.head` `audit.head` `procurement.head` | `Dept@2026` |

> ⚠️ **مهم:** غيّر كلمات المرور من شاشة «إدارة المستخدمين» بعد أول تسجيل دخول.

## حسابات الجهات الخارجية

لكل جهة خارجية حساب دخول خاص يتيح لها رؤية مراسلاتها فقط وإرسال مراسلات واردة إلى المديرية، دون الوصول إلى أي من المراسلات الداخلية.

- **الإنشاء:** من شاشة «المراسلات الخارجية» ← «إدارة الجهات» ← «إضافة جهة». تُنشأ الجهة مع حسابها وتظهر بيانات الدخول (اسم المستخدم وكلمة المرور الابتدائية) **مرة واحدة** عند الإنشاء — سجّلها فوراً وسلّمها للجهة.
- **الإرسال:** تُسجَّل المراسلات التي يرسلها حساب الجهة بصفتها «واردة» على اسم جهته تلقائياً، وتصلك إشعارات فورية بها.
- **الإشعارات:** عند تسجيل صادر موجّه للجهة يصل إشعار لحسابها، والنقر على الإشعار يفتح الرسالة مباشرة.
- **إعادة تعيين كلمة المرور:** من «إدارة الجهات» ← زر «إعادة تعيين كلمة المرور» بجانب الجهة. تعطيل الجهة يعطّل حسابها تلقائياً.
- **الترقية:** قواعد البيانات القائمة تُرقّى تلقائياً عند تشغيل `npm run setup`، وتُنشأ حسابات للجهات الموجودة مسبقاً.

## خطوات التثبيت على Windows Server

### 1. المتطلبات

- **Node.js 20 أو أحدث**: حمّله من https://nodejs.org (نسخة LTS) وثبّتها بالإعدادات الافتراضية.
- **SQL Server 2022 Express** (مجاني): حمّله من https://www.microsoft.com/sql-server/sql-server-downloads واختر **Basic/Express**. أثناء التثبيت اختر **Mixed Mode** وحدد كلمة مرور لحساب `sa`.
- **SQL Server Management Studio (SSMS)** — اختياري، لإدارة قاعدة البيانات يدوياً.

### 2. تجهيز قاعدة البيانات

الطريقة الأسهل (تُنشئ القاعدة والجداول والحسابات تلقائياً):

```bat
cd server
npm install
npm run setup
```

يجب أن يظهر في النهاية: `اكتمل الإعداد بنجاح ✅`

> إذا أردت إنشاء القاعدة يدوياً: افتح `database/schema.sql` في SSMS ونفّذه على `master`، ثم نفّذ `npm run setup` لإدخال الحسابات الأولية فقط.

### 3. إعداد الاتصال

افتح الملف `server/.env` (أنشئه من `server/.env.example` إن لم يكن موجوداً) وعدّل القيم:

```env
DB_SERVER=localhost        # اسم الخادم أو localhost
DB_NAME=MurasalatDB
DB_USER=sa
DB_PASSWORD=كلمة-مرور-sa-هنا
DB_PORT=1433
JWT_SECRET=ضع-هنا-نصاً-عشوائياً-طويلاً
PORT=3001
```

### 4. بناء الواجهة وتشغيل النظام

```bat
cd client
npm install
npm run build

cd ..
cd server
npm install
npm start
```

أو ببساطة شغّل الملف الجاهز: **`start-windows.bat`** بالنقر المزدوج.

### 5. الوصول من أجهزة الشبكة

بعد التشغيل، يصبح النظام متاحاً على:

- على الخادم نفسه: `http://localhost:3001`
- من أي جهاز بالشبكة: `http://عنوان-IP-الخادم:3001`

**لا تنسَ:** افتح المنفذ **3001** في جدار حماية Windows:

```powershell
New-NetFirewallRule -DisplayName "Murasalat" -Direction Inbound -Port 3001 -Protocol TCP -Action Allow
```

### 6. إبقاء النظام يعمل دائماً (اختياري)

شغّل السكربت عبر **NSSM** كخدمة Windows كي يعمل تلقائياً بعد إعادة تشغيل الخادم:

```
nssm install Murasalat "C:\...\murasalat\server\node.exe" "C:\...\murasalat\server\src\index.js"
nssm set Murasalat AppDirectory C:\...\murasalat\server
nssm start Murasalat
```

## الصلاحيات

| الدور | الصلاحيات |
|---|---|
| مدير النظام | كل شيء: إدارة المستخدمين، عرض كل المراسلات، الإحصاءات |
| مدير المديرية | بريده الوارد والصادر، لوحة المؤشرات، دليل الأقسام |
| رئيس قسم | بريده الوارد والصادر، إنشاء المراسلات والردود والمرفقات |

- كل مستخدم يرى **فقط** مراسلاته (الواردة والصادرة والمؤرشفة).
- المستلم يظهر تلقائياً «قرأها» عند فتح المراسلة، ويعود إشعار القراءة للمرسل.
- الأرشفة تُخفي المراسلة من الصناديق وتحفظها في صندوق «الأرشيف».
- المرفقات: حتى 15 ميجابايت للملف، بصيغ pdf/docx/xlsx/jpg/png/zip وغيرها.

## حل المشكلات

| المشكلة | الحل |
|---|---|
| `Login failed for user 'sa'` | تأكد من `DB_PASSWORD` في `server/.env` ومن تفعيل Mixed Mode في SQL Server |
| لا يتصل أحد من الشبكة | جدار الحماية: اسمح بالمنفذ 3001 (الخطوة 5) |
| صفحة فارغة بعد التحديث | أعد بناء الواجهة: `cd client && npm run build` |
| الإشعارات الفورية لا تظهر | تحقق أن جميع الأجهزة تفتح `http://IP:3001` وليس `localhost` (المصدر يجب أن يكون واحداً) |
| فشل `npm run setup` | تأكد أن خدمة SQL Server تعمل (SQL Server Configuration Manager) |

## النسخ الاحتياطي

انسخ دورياً:
1. قاعدة البيانات: من SSMS ← Backup، أو `sqlcmd -Q "BACKUP DATABASE MurasalatDB TO DISK='D:\Backup\Murasalat.bak'"`.
2. مجلد المرفقات: `server/uploads`.
